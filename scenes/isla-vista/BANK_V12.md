# Connected bank intermediate

This additive checkpoint retains the geographic lagoon and base support, then
adds authored coherent understory patches, curved blades, contact litter and
bounded organic-contact tint. It is not a current botanical inventory.

The saved native 600 × 420 / 32-sample image is
`renders/lagoon-overlook-connected-bank_600_32.png`. It has visible limits:
large pale paths, flat-looking bank matrix, narrow source-GIS asphalt slivers,
repeated shrubs and a dominant dormitory. It is an intermediate step, not a
completed photorealism claim.

After the parent README's verified v11b materials/build steps, run each of
these through its documented CPU/lock/RSS/deadline guard:

```sh
python replay_bank_v12.py build
python replay_bank_v12.py check
python replay_bank_v12.py capture --width 600 --spp 32
```

`verification/v12/GEOMETRY_CONTRACTS.json` verifies that base ground positions,
normals, UVs, triangle IDs and packet headers are unchanged. Only 69,990 soil
vertex tints change within bounded ratios. All serialized understory vertices
remain above the shared support; the minimum clearance is approximately
0.937 mm. The added 12,837 clumps and 21,369 litter leaves are explicit authored
abundance/season estimates. All 128,606.96 m² of mapped lagoon are retained.

Source photographs remain linked observations, never bundled pixels or image
textures. The small restoration-basin dimensions and level, architectural
detail, species forms, clear daylight and viewpoint remain authored estimates.
The whole-region residential pipeline is documented separately in
`whole-region/README.md`; this bank checkpoint does not itself add the OSM
residential scene to its bounded lagoon assembly.
