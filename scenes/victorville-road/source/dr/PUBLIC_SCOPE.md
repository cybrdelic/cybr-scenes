# Execution closure and provenance

The selected entry point is the sequence in README.md. Old revision letters in
imported filenames identify source dependencies, not selectable scene defaults.

Mandatory inputs include the approved microbed, physical asphalt height data,
the CH/CE/CF support and stock fields, CL layout, DH two-body specimen bank,
DL baseline cap needed for DM admission, DM current cap, and DR fixed world
status/roles/catalogue and exact view subset. Hash-checked renderer snapshots
are retained wherever original source uses adjacent-path module lookup.

Mandatory historical contracts include the Y/Z semantic geometry/material
fingerprints, AV component replay templates, original payload and shape-review
admission records. They are live validation inputs. Unreferenced historical
render/resource reports, bytecode, images and generated scene caches are excluded.

Original mineral/asphalt generator code is unchanged. Directory aliases preserve
its existing lookup behavior while avoiding duplicate selected source banks.
Two binary aliases reuse exact input bytes; source-lock-protected files remain
regular files. Git naturally shares all other identical blob contents.

The actual recovered DR image exactly matches every RGB pixel of the saved
2000 x 1334 image. Its PNG metadata differs. The final trimmed source configuration
is checked separately against that rendered configuration. No new visual gain
is claimed by this recovery. A second complete from-zero build of the final
publication folder has not been run.
